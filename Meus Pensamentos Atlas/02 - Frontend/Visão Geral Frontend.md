# Visão Geral do Frontend (Angular 18)

O frontend utiliza **Angular 18** com uma abordagem moderna (Standalone Components e Signals) para garantir performance e facilidade de manutenção.

## 1. Stack Tecnológica

- **Framework**: Angular 18 (Standalone)
- **UI Library**: PrimeNG 18
- **Estilização**: Tailwind CSS + SCSS
- **Gerenciamento de Estado**: Angular Signals + Services com BehaviorSubject
- **Ícones**: PrimeIcons

## 2. Componentes Implementados

### 2.1 Login (`/login`)
- Interface profissional e responsiva.
- Validação de formulários reativos.
- Integração com o serviço de autenticação do backend.

### 2.2 Dashboard (`/dashboard`)
- Visão geral para administradores e comandantes.
- Utiliza PrimeNG Charts para visualização de dados (Equipamentos por tipo, status, etc.).

### 2.3 Lista de Equipamentos (`/equipamentos`)
- Tabela avançada com paginação, ordenação e filtros.
- Exportação de dados.
