# Meus Pensamentos Sigmat

Este diretório é o vault Obsidian do projeto SIGMAT. Ele foi organizado para facilitar a navegação entre:

- Visão geral do projeto
- Documentação técnica do backend e frontend
- Modelo de dados e workflows
- Evolução do pensamento e etapas de progresso

## Como usar

1. Abra esta pasta no Obsidian.
2. Comece por **[[SIGMAT - Mapa de Conteúdo]]** para ver o índice principal.
3. Use **[[Manual do Obsidian]]** para entender a estrutura e as melhores práticas.
4. Navegue pelas pastas:
   - `00 - Projeto`
   - `01 - Backend`
   - `02 - Frontend`
   - `03 - Banco de Dados`
   - `04 - Workflows`
   - `05 - Progresso`


## Pontos chave

- `Evolução do Pensamento.md` mostra a jornada do projeto.
- `Fluxo do Sistema SIGMAT.md` descreve o fluxo entre frontend, backend e banco.
- `Template de Nota SIGMAT.md` contém um modelo para criar novas notas.
- `00 - Projeto/SIGMAT V2 - Mapa de Conteúdo.md` é o índice técnico detalhado.
- `Cronograma de Implementação SIGMAT.md` descreve as fases de trabalho por parte.

## Dicas

- Ative o Graph View para ver conexões entre as notas.
- Use backlinks para manter as relações de contexto entre as páginas.
- Sempre crie notas novas com o modelo `Template de Nota SIGMAT.md`.
